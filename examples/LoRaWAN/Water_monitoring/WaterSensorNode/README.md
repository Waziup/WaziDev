# KijaniSpace Water Sensor Node

An open, solar-powered LoRaWAN station for continuous water-quality monitoring in aquaculture. It
was developed for fish-farm sites on Lake Victoria. Every 30 minutes the node measures five
parameters and transmits them to a [WaziGate](https://github.com/Waziup/wazigate-edge) LoRaWAN
gateway:

| Parameter | Sensor | Interface |
|---|---|---|
| Water temperature | DS18B20 | 1-Wire |
| pH | Atlas Scientific EZO-pH, galvanically isolated | I²C |
| Electrical conductivity | Atlas Scientific EZO-EC, galvanically isolated | I²C |
| Dissolved oxygen | DFRobot SEN0680 (optical) | RS485 / Modbus RTU |
| Turbidity | Yosemitech Y511-A (self-cleaning wiper) | RS485 / Modbus RTU |

The controller is a **WaziSense v2** (ATmega328P with an SX1276 LoRa radio). All sensor
electronics sit on the **KijaniSpace Carrier**, a 100 × 100 mm, two-layer PCB:
- the modules plug into sockets and every probe connects to a screw terminal or SMA jack;
- the board arrives fully assembled from the manufacturer, with nothing to hand-solder.

## Design highlights

- **Energy-aware.** Every sensor group is power-gated and switched off between measurements. The
  node hibernates below 3.6 V and still reports its battery voltage while hibernating. From a full
  18650 cell it runs about 25 days without sun.
- **Isolated electrochemistry.** pH and EC each sit behind their own isolator, on a separate ground
  island bounded by routed slots in the PCB. This removes the ground loop between the two probes.
- **Remote calibration.** pH (three points) and EC (dry + one point) can be calibrated over LoRaWAN
  downlinks from the gateway dashboard. The node checks that the reading is stable and plausible
  before it calibrates, and reports the result.
- **Reproducible hardware.** The PCB is generated by scripts from a single source. The build checks
  the routing, the isolation barriers, the silkscreen, the assembly placement and the fabrication
  archive automatically.

## Getting started

1. **Hardware:** order the carrier from the fabrication files in `pcb/out/fab/`
   (see [`pcb/README.md`](pcb/README.md)). Source the remaining parts from the Parts List.
2. **Firmware:** enter your device's LoRaWAN credentials in `WaterSensorNode.ino` and flash it
   (see below).
3. **Assembly and installation:** follow the Node Deployment guide.
4. **Gateway:** in the WaziGate dashboard's browser console, run
   [`create_wazigate_device.js`](create_wazigate_device.js) with the node's address and key filled in.
   It creates the LoRaWAN device with the XLPP codec, the named sensors and the calibration
   actuators. For a device that already exists, run
   [`update_wazigate_device.js`](update_wazigate_device.js) instead.
5. **Calibration:** calibrate pH and EC on site with the Probe Calibration guide.
6. **Troubleshooting:** the Node Bring-Up guide, from the stage that fails.

## Firmware

| | |
|---|---|
| Target | WaziSense v2: ATmega328P, 3.3 V, 8 MHz ("Arduino Pro or Pro Mini, 3.3 V, 8 MHz") |
| Libraries | WaziDev, xlpp, LowPower, Vcc ([WaziDev repository](https://github.com/Waziup/WaziDev)); OneWire; DallasTemperature |
| Serial | 38400 baud |
| Radio | LoRaWAN ABP, EU868, SF12 |

**LoRaWAN credentials:** the device address and keys are set at the top of `WaterSensorNode.ino`.
Use placeholders in any public copy, and never commit real credentials.

**Build variants.** Two compile-time switches; every combination fits in the 30,720 bytes of
program memory:

| `VERBOSE_LOG` | `ENABLE_LORA_CAL` | Program memory | Use |
|---|---|---|---|
| 0 | 1 | 27,670 bytes (90 %) | **deployment**: concise log, remote calibration |
| 1 | 1 | 27,974 bytes (91 %) | bench: full diagnostic log, remote calibration |
| 1 | 0 | 26,508 bytes (86 %) | bench: full log; calibrate with `EZOCal` |

**Uplink payload** (XLPP / Cayenne LPP). A failed reading is omitted, never sent as zero.

| Channel | Content |
|---|---|
| 1 | water temperature, °C (DS18B20) |
| 2 | battery voltage, V |
| 3 | pH |
| 4 | dissolved oxygen, mg/L |
| 5 | conductivity, µS/cm |
| 6 | turbidity, NTU (capped at 327) |
| 7 | temperature at the oxygen probe, °C (cross-check of channel 1) |
| 9, 10 | pH / EC calibration result, sent once after a calibration |

**Downlinks.** WaziGate v3 forwards the value pushed to an actuator as plain text, so the node
interprets the value itself:

| Value | Action |
|---|---|
| `7`, `4`, `10` | pH calibration: mid, low, high |
| `-3`, then e.g. `84` | EC calibration: dry, then single point in µS/cm |
| `-1` / `-2` | clear pH / EC calibration |
| `300` … `3600` | measurement interval in seconds (whole minutes) |

The Probe Calibration guide gives the full procedure, the result codes and the limits of remote
calibration.

## Hardware

The carrier board is generated with KiCad 10 from Python scripts in `pcb/gen/`. All paths are
relative to the repository; only the KiCad installation is machine-specific and can be set with
`KICAD_DIR` (or `KICAD_CLI` and `KICAD_PYTHON` individually). Rebuild with:

```bash
bash pcb/gen/build.sh
```

```bash
bash pcb/gen/fab.sh
```

`build.sh` regenerates and routes the board. `fab.sh` produces the Gerber, drill, BOM and placement
files and verifies them. [`pcb/README.md`](pcb/README.md) documents the design, the checks and the
manufacturing notes.
